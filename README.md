# Atlas FundedBeyond LMS

Atlas LMS is a multi-tenant, white-label learning management SaaS platform.

## Status

Development mode.

## Source of truth

All implementation must follow the locked Atlas LMS artifacts in `docs/locked`.

## Hard rules

- Do not redesign the product.
- Do not create unapproved screens.
- Do not create unapproved APIs.
- Do not create unapproved permissions.
- Do not create unapproved workflows.
- Do not create unapproved entities.
- Do not hardcode tenant-specific behavior.
- FundedBeyond Academy is Tenant #1 configuration only.
- No secrets may be committed.
