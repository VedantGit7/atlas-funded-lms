2026-08-15 audit was finding 6 critical and 18 high issues. It was empty because
nothing had detected them, not because they had been assessed — which is the
failure mode a register exists to prevent, and is recorded as audit finding H18.

## Rules

- P0 security or isolation exceptions block `READY_FOR_STAGING`.
- Document any waiver with owner, expiry, and compensating controls.
- Never waive RLS, `withTenantTx`, `can()`, or platform scope requirements.
- An empty register is a claim that someone looked, not that nobody did.

## Review cadence

Review at each release candidate and before CTO production sign-off.
`release:evidence:validate` enforces the freshness of the automated half of this
picture; this file is the manual half and has no such guard, so the cadence is
the only thing keeping it honest.
