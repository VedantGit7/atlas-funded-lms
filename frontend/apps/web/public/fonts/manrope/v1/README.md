# Manrope v1

Unmodified WOFF2 files from the FundedBeyond brand kit (v1, October 2026, `03 Fonts`), a free Google Font under the SIL Open Font License 1.1. Used only by the Sky Glass theme skin (`src/styles/skins/sky-glass.css`). The manifest records the source, checksums, the license checksum and the fallback metrics. OFL.txt is the redistribution license.

CSS: `src/styles/manrope.css`. Public URLs contain the version and a content hash; never overwrite deployed bytes at these URLs. Update the version, CSS, manifest, preloads and regression expectations together.
